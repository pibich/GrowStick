# GrowStick

Aplikasi catatan tempel (sticky note) digital. Tulis catatan, pilih warna, atur visibilitas (privat / tautan saja / publik), dan lihat catatan publik di papan beranda. Mendukung mode offline dan dua bahasa (ID/EN).

## Tech Stack

- **Laravel 13** (PHP 8.3+)
- **Livewire 4** — Single File Components + Alpine.js
- **Tailwind CSS 4** + **Vite 8**
- **SQLite** (database)
- **PHPUnit** + **Laravel Pint**
